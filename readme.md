# ai-howto

AI 工具與自動化的操作筆記、研究報告與設定指南。依主題分類如下：

## 目錄結構

| 目錄 | 主題 |
|---|---|
| `trading/` | 投資交易與行情監控：台股/證交所 API（twse-monitor、twse-api）、美股 Alpaca、黃金/KGI 監控、模擬盤 |
| `voice-avatar/` | 語音與數位人：GPT-SoVITS、ElevenLabs、Kokoro TTS、Whisper、數位人 avatar、JARVIS 管線 |
| `openclaw/` | OpenClaw：安裝/外掛/Skills、管理面板、備份還原、sub-agent 團隊配置、ClawHub 發布 |
| `openclaw-scrum/` | OpenClaw Scrum 自動化：任務追蹤、成員配置審查 |
| `qclaw/` | QClaw：CLI 用法、agent 配置、用量限制解法 |
| `security/` | 安全防護：Prompt Injection 防禦、ClawSec 分析、AWS 安全文章 |
| `llm-local/` | 本地模型與推理環境：Qwen 下載/切換、MNN Metal 建置；OpenRouter fallback 配置 |
| `llm-router/` | LLM Router 評估報告（2025） |
| `task-workflow/` | 任務自動化工作流：ideas2tasks 系統、任務執行器設計、GitHub Projects 整合、Scrum 規範 |
| `ai-agents-comparison/` | Coding agents 比較（pi / opencode / openclaw / hermes）與 MindNav 評測 |
| `claw-sessions-issue/` | Claw sessions 對話存檔議題 |

## 檔案命名慣例

- 中文或英文皆可，主題明確
- 研究類文件建議標註日期（如 `tw-stock-top5-analysis-2026-04-21.md`）

# 黃金存摺價格監控

台灣銀行黃金存摺價格自動監控系統，支援價格變動通知、特定價格點位監控與每日收盤報告。

---

## 📊 監控配置

| 項目 | 設定 |
|------|------|
| 監控標的 | 台灣銀行黃金存摺 |
| 監控時段 | 09:00 - 15:30（週一至週五） |
| 檢查頻率 | 每 10 分鐘 |
| 價格閾值 | ±50 元（可調整） |
| 通知管道 | Telegram |

---

## ⏰ 定時任務

| 任務 | 時間 | 說明 |
|------|------|------|
| 價格監控 | 每 10 分鐘 (09:00-15:30) | 價格變動 ≥ 閾值時通知 + 價格點位觸發通知 |
| 每日報告 | 15:30 (週一至週五) | 發送當日最終牌價 + 走勢圖 |

---

## 🎯 價格點位監控

可設定特定價格點位，當價格觸發時發送通知。

### 觸發邏輯

| 類型 | 觸發條件 |
|------|----------|
| 買入 (buy) | 價格 **跌到或跌破** 目標價 |
| 賣出 (sell) | 價格 **漲到或突破** 目標價 |

### 使用方式

```bash
# 新增價格點位
# 格式: price:type:label
# type: buy (買入) 或 sell (賣出)

# 新增買入點位（價格跌到 4500 時通知）
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --add-target 4500:buy:進場點

# 新增賣出點位（價格漲到 5000 時通知）
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --add-target 5000:sell:出場點

# 列出所有價格點位
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --list-targets

# 移除價格點位
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --remove-target 4500

# 重置所有點位的觸發狀態（讓已觸發的點位可以再次觸發）
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --reset-targets
```

### 點位狀態

- ⏳ **待觸發**：尚未觸發，等待價格到達
- ✅ **已觸發**：已觸發過，不會再次通知（除非重置）

---

## 📈 報告內容

### 價格變動通知
- 變動方向（上漲/下跌）
- 變動金額與百分比
- 目前價格與前次價格

### 價格點位觸發通知
- 觸發類型（買入/賣出）
- 目標價格與目前價格
- 備註說明

### 每日收盤報告
- 當日最終牌價
- 與前一交易日的漲跌比較
- 價格走勢圖

### 走勢圖基準日邏輯

| 當日 | 比較基準 |
|------|----------|
| 週一 | 上週五收盤 → 週一走勢 |
| 週二 ~ 週五 | 前一交易日收盤 → 當日走勢 |

## 🛠️ 使用方式

### 查看當前配置
```bash
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --config
```

### 調整價格變動閾值
```bash
# 設定為 30 元
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --set-threshold 30

# 設定為 100 元
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --set-threshold 100
```

### 手動檢查價格
```bash
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --check
```

### 手動發送日報
```bash
python3 ~/.qclaw/workspace/scripts/gold_monitor.py --daily
```

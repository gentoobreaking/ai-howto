## 執行摘要

ElevenLabs 是目前業界頂尖的 AI 語音合成平台，提供 TTS（文字轉語音）、語音克隆、語音轉文字、音效生成等完整音訊 AI 服務。**免費版僅限非商業用途**，付費方案從 $6/月起即可取得商業授權。用戶保留輸入與輸出內容的所有權，但需授予 ElevenLabs 廣泛的使用授權以改善服務。關鍵限制包括：禁止用於政治競選、詐騙、未經授權的聲音模仿，以及不得將輸出用於訓練其他 AI 模型。

## 1. 核心技術架構

### 1.1 TTS 模型

| 模型 | 延遲 | 用途 |
|------|------|------|
| **Flash/Turbo** | ~75ms | 低延遲實時應用 |
| **Multilingual v2/v3** | ~250-300ms | 多語言高品質合成 |

- 支援 32+ 種語言
- 音質：128kbps 起，Pro 以上支援 192kbps / 44.1kHz PCM
- 支援語音風格控制（如 [sarcastically]、[whispers] 等標記）

### 1.2 語音克隆（Voice Cloning）

| 類型 | 名稱 | 特點 |
|------|------|------|
| **IVC** | Instant Voice Cloning | 快速克隆，少量音訊即可 |
| **PVC** | Professional Voice Cloning | 專業級品質，需較多音訊素材 |

### 1.3 其他功能

- **Speech to Text**：實時或批次語音轉文字
- **Sound Effects**：文字生成音效
- **Voice Isolator**：人聲分離
- **Music**：AI 音樂生成
- **Voice Design**：用文字描述生成新聲音
- **Dubbing**：自動配音與配音工作室

### 1.4 API 與 SDK

- **REST API**：完整的 API 參考文件
- **SDK**：TypeScript/JavaScript、Python
- **認證**：API Key 方式
- **延遲**：最低可達 5c/分鐘（Business 方案）
- **串流**：支援串流輸出

### 1.5 企業級功能

- **合規認證**：SOC 2、HIPAA、GDPR
- **資料落地**：EU Data Residency 選項
- **零保留模式**：Zero Retention mode
- **SSO**：企業版支援自定義 SSO

## 2. 使用條款與授權（重要）

### 2.1 商業使用權限

| 用戶類型 | 商業使用 | 限制 |
|----------|----------|------|
| **Free User** | ❌ 禁止 | 僅限非商業用途，需使用個人信箱 |
| **Paid User** | ✅ 允許 | 需遵守 Prohibited Use Policy |

> **關鍵條款**：免費用戶若以企業信箱註冊，ElevenLabs 可能將該企業視為 Controller，並可依該企業指示對帳戶採取行動。

### 2.2 內容版權歸屬

**用戶保留所有權**：
- ✅ 用戶保留 Input（輸入）的所有權利
- ✅ 用戶保留 Output（輸出）的所有權利
- ⚠️ Output 不包括 ElevenLabs 的基礎 AI 模型（Voice Models / LLMs）

### 2.3 授予 ElevenLabs 的授權（極為廣泛）

用戶授予 ElevenLabs 以下授權以使用、複製、修改、改編、發布、翻譯、創建衍生作品、分發、公開展示內容：

| 授權屬性 | 說明 |
|----------|------|
| **永久且不可撤銷** | perpetual and irrevocable |
| **非獨家** | 用戶可同時授權給他人 |
| **免版稅** | royalty-free and fully paid |
| **全球適用** | worldwide |
| **可再授權** | sub-licensable through multiple tiers |

**範圍包括**：
- 提供服務（含信任與安全功能）
- 改善服務
- 開發新服務和產品

**聲音特殊條款**：
- ElevenLabs **不會**在未經許可的情況下單獨商業化用戶的聲音
- 但用於改善服務和開發新產品的授權仍然適用

### 2.4 禁止用途（Prohibited Use Policy）

根據 2025 年 9 月 3 日版本，以下用途嚴格禁止：

| 類別 | 禁止行為 |
|------|----------|
| **兒童安全** | 創建涉及未成年人的色情內容、兒童剝削、網路霸凌 |
| **非法行為** | 侵犯智慧財產權、侵犯隱私、非法商品交易 |
| **影響他人福祉** | 未經授權提供專業建議（金融、法律、醫療）、高風險自動決策 |
| **詐騙與濫用** | 欺騙他人、金融詐騙、繞過語音驗證、未經授權自動撥號 |
| **未經授權模仿** | 未經同意複製他人聲音、造成傷害的模仿、AI 生成欺騙 |
| **政治活動** | 選民壓制、候選人模仿、政治競選活動 |
| **網路安全** | 未經授權的網路存取、惡意軟體、監控 |
| **暴力與仇恨** | 暴力威脅、極端主義、歧視、騷擾、自殺促進 |
| **競爭與訓練** | 使用輸出訓練其他 AI 模型、與 ElevenLabs 競爭、轉售服務 |
| **政府實體** | 政府機構使用需事先書面授權 |

### 2.5 專利相關

條款中**未明確提及專利授權**，但包含以下相關條款：

- **禁止逆向工程**：不得反編譯、反組譯或以其他方式逆向工程服務的任何部分
- **禁止發現源碼**：不得做任何可能發現或揭示源碼或模型權重的事
- **競爭禁止**：不得使用服務或其輸出來研究開發與 ElevenLabs 競爭的產品、模型或服務

> ⚠️ **注意**：若用戶所在司法管轄區明確禁止此類限制，必須事先獲得 ElevenLabs 書面授權。

## 5. 結論與建議

### 5.1 適合場景

✅ **推薦使用**：
- 高品質語音內容創作（有聲書、播客、影片配音）
- 需要語音克隆的個人化應用
- 多語言內容在地化
- 遊戲、動畫角色配音
- 企業級語音代理（ElevenAgents）

❌ **不適合**：
- 純個人非商業用途且預算極低（Edge TTS 免費替代）
- 政治競選相關用途
- 需要訓練自有 AI 模型的場景
- 政府機構（需特別授權）

### 5.2 授權風險提醒

| 風險項目 | 說明 |
|----------|------|
| **內容授權過廣** | 用戶內容可被 ElevenLabs 用於「改善服務」和「開發新產品」，範圍模糊 |
| **聲音權利** | 雖承諾不單獨商業化用戶聲音，但改善服務的授權仍適用 |
| **競爭禁止** | 不得使用輸出訓練競爭模型，限制技術自主權 |
| **政治限制** | 禁止政治競選用途，可能影響部分組織 |

### 5.3 建議

1. **免費用戶**：若僅為個人使用，可考慮 Edge TTS（免費）作為替代
2. **商業用戶**：Starter 方案 ($6/月) 即可取得商業授權，性價比高
3. **企業用戶**：建議選 Enterprise 方案以取得自定義條款和 HIPAA 合規
4. **法律審查**：若涉及敏感內容或大規模部署，建議法律顧問審查條款
5. **備份策略**：定期備份生成的語音內容，避免服務中斷影響
